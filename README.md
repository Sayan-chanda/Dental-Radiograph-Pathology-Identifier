#Dental Radiograph Pathology Identifier

## Overview
An academic project investigating AI-based detection and localization of dental pathologies in panoramic radiographs.

## Target Pathologies
-Caries
-Impacted teeth
-Periapical lesions

## Proposed Approach
1. Prepare and inspect the DENTEX dataset.
2. Train a pretrained YOLO baseline model.
3. Integrate a selected attention mechanism.
4. Compare both model using object-detection metrics.

## Evaluation
-Precision
-Recall
-F1-score
-mAP@50
-mAP@50-95
-IoU
-Class wise Performance

## Project Status
Implementation and experiments are in progress.

DENTEX: https://dentex.grand-challenge.org/
